Group Journal

The Journal now has a Group tab for encounters where group members participated and had Battle Scrolls installed

Overview:
- Sortable comparison table with columns for each boss, DPS, Crit%, DTPS, HPS, Alive%, and Deaths

Per-player detail:
- Damage output: DPS, total, crit%, max hit, direct%, AoE%, damage by type
- DPS rank and comparison vs DD average
- Survivability: DTPS, alive time, death count, top incoming damage abilities, death recaps
- Healing output: raw HPS, effective HPS, overheal, self-healing
- Per-boss damage bars with damage composition stats
- Per-boss damage taken

Group context tooltips on the existing tabs when the data is available:
- Boss target rows on Damage Done tabs show per-member DPS and contribution %
- DPS and Boss DPS rows show per-member DPS breakdown
- DTPS and damage source rows on Damage Taken show per-member DTPS
- Damage composition stats (type, direct vs DoT, AoE vs single-target) show DD average for comparison
- Healing Out: raw HPS shows group total and per-member HPS, overheal shows per-member overheal %
- Self Healing: raw HPS shows per-member self-healing HPS, overheal shows per-member overheal %

Death Tracking

Death recaps are now saved with encounters and displayed in:
- Overview tab: death count in the damage taken section
- Damage Taken tab: deaths listed with timestamps, with recap viewable in the tooltip
- Group tab: first and last death per player with full attack details

Minor changes:
- Overview panel damage composition section now shows Direct % instead of DoT % because that's the world we live in
- Overview panel now always shows Direct % and AoE % instead of showing it only if it's between 5% and 95%
- Event Zone override: a new toggle appears in settings when Night Market is active, allowing you to record fights there regardless of your Overland/Instances settings
- Both DPS meters now appear behind other UI elements such as loot history instead of above (do you like it better? do you hate it? let me know!)
- "Overview" item is always selected by default on all tabs. This increases memory usage a bit (and it's only released on UI reload) but you didn't want to have free memory anyway, did you?
- Gamertags are now consistently displayed without @ symbol
- "Hodor" and "Bars" group meters now display current fight duration in the header
- Changed sounds that play when opening and closing dialogs when using filters or managing instances

Localization:
- Fixed minor pluralization issues
- Made "stacks" terminology to be consistent with item sets wording in Russian (стак -> заряд) and German (Stapel -> Kumulation)
